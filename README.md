This repository contains the latex source for the "Persistence Mechanics V: Decay as a Conditional Routing Model"

The paper applies Persistence Mechanics to the Quantum Vacuum to provide an example of recursive systems and decay. First by showing how ontop of the E8 substrate some information protocols can persist which match the elementary particles and then with that explains how they decay also providing a model for elementary particle decay.

The rendered version can be viewed here: [https://meta-r0ze.github.io/PM_Quantum_Vacuum_V/Persistence_Mechanics_of_the_Quantum_Vacuum_V.pdf](https://meta-r0ze.github.io/PM_Quantum_Vacuum_V/Persistence_Mechanics_of_the_Quantum_Vacuum_V.pdf)
