\section{Formalization and Reproducibility}
The companion \texttt{lean} folder uses Lean 4.34.1 and pinned mathlib dependencies shared with Paper I. Running \texttt{./check.sh} builds the library and checks every project declaration for unapproved transitive axioms. The allowlist contains only Lean's standard logical foundations.

The modules check routing descent and conserved labels; constant-hazard survival identities; partial-width sums and lifetime scaling; and mass-dimension bookkeeping. The fifth-power result assumes a local four-fermion interaction and the stated scaling of its amplitude. No spinor matrix element, phase-space integral, measured particle input or microscopic routing law is silently promoted to a proved physical fact.
